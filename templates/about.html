About The Project

Early Stage Disease Diagnosis Using Nail Image Processing

Project Objective

This project develops an early stage disease diagnosis system using deep learning techniques to analyze human nail images. By analyzing nail characteristics and abnormalities, the system detects and diagnoses early signs of various diseases, aiding healthcare professionals and individuals in timely intervention and disease management.

Technology Stack

  • Deep Learning Model: VGG16 (Transfer Learning)
  • Framework: TensorFlow / Keras
  • Web Framework: Flask
  • Frontend: HTML5, CSS3, JavaScript
  • Language: Python
  • Libraries: NumPy, Pillow, scikit-learn
